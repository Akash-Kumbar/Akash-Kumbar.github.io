Camera-Based Vehicle Functions

Completed as a part of Bosch's PRIXEL program

Python PyTorch ONNX OpenCV

As part of Bosch’s PRIXEL program, our team developed a real-time system for detecting potholes and speed breakers using object-detection models.

We curated and annotated a dataset representing Indian road conditions, where speed breakers are often unmarked and can be difficult for drivers to anticipate. Using this dataset, we developed a camera-based detection pipeline designed to identify these road hazards in real time.

The project gave me practical experience in dataset preparation, annotation, model development, and applying computer vision to a real-world road-safety problem.
