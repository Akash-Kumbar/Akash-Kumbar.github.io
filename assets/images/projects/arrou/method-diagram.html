ARROU: Adversarially Robust Rank-One Unlearning Framework

Objective: Edit a model to unlearn targeted knowledge or capabilities and refuse related queries robustly, while preserving performance on retain and utility tasks.

1Specify Edit

Target a fact or capability (s, r, o) → (s, r, o*), or a harmful behavior to unlearn.

Edit specification
  • Subject or trigger: s
  • Relation or intent: r
  • Original answer to forget: o
  • Desired safe response: o*
→

2Collect Key–Value Vectors

Use prompts that elicit the target behavior and extract key and value vectors at a decisive MLP layer ℓ.

  • Clean prompts: Pclean
  • Key vector: k = hℓ(x)K
  • Value vector: v = hℓ(x)V
→

3Compute Rank-One Edit (r-ROME)

Find a rank-one update that maps the key toward a new value inducing safe behavior.

  • Target value: v* from a refusal or safe context
ΔWℓ = α · ((v* − v)kᵀ) / (‖k‖² + ε)
  • Apply edit: Wℓ ← Wℓ + ΔWℓ
→

4Evaluate Edited Model

Evaluate on forget or attack sets and on retain sets. If the model remains vulnerable, invoke the attacker.

  • Forget sets: suffix, latent, many-shot
  • Retain sets: utility and general QA
  • Metrics: ASR, answer probability, ROUGE-L, refusal rate

Minimax Loop (Adversary-in-the-Loop)

5Attacker: Find Breaking Contexts (LAT)

Search for prompts and latent perturbations that make the edited model fail, relapse, or stop refusing.

Search spaces
  • Prompt space: suffixes, paraphrases, templates, many-shot demonstrations
  • Latent space at layer ℓ: additive perturbations δ with ‖δ‖p ≤ ε
Attack objective arg maxx,δ Lattack(Medit, x, δ)

Output: adversarial set A containing breaking examples.

Breaking examples A Updated edit
→ ←

6Editor: Harden Edit with Adversarial Key Averaging

Recompute key and value statistics on adversarial contexts, then apply a new rank-one update.

  • Keys on adversarial set: {kiadv}
  • Robust key: k̄ = (1/N) Σ kiadv
  • Robust safe value: v̄*
ΔWℓ = α · ((v̄* − v̄)k̄ᵀ) / (‖k̄‖² + ε)
  • Apply: Wℓ ← Wℓ + ΔWℓ
Converged?
ASR below τ or no improvement
No → repeat loop Yes ↓

7Robustly Edited Model

Robust refusal: produces safe answers on targeted and related queries, including suffix, latent, and many-shot attacks.

Utility retention: preserves behavior on retain prompts with minimal drift in answer probability and ROUGE-L.

→

Reported Metrics

Robustness

  • ASR ↓
  • ASR vs. context length
  • Lower power-law exponent

Utility / Retain

  • Average ROUGE-L ↑
  • Retain answer probability ↑
  • Minimal semantic drift

Efficiency

  • Layer-local update
  • Rank-one edit
  • No full retraining
Notation
ℓ: edited layer hℓ(x): hidden state k, v: key/value vectors Wℓ: MLP weight matrix ΔWℓ: rank-one update Medit: edited model ASR: attack success rate
